# Bank-Management-System-(C++)
A console-based application built in C++ to simulate basic banking operations. The system allows account creation, deposit, withdrawal, and balance inquiry. It demonstrates object-oriented programming concepts such as classes, inheritance, and encapsulation.

## 🛠️ Technologies Used
- C++ Programming
- Object-Oriented Programming (OOP)
- Classes & Objects
- Inheritance & Polymorphism

## ✨ Features
- Create new bank accounts
- Deposit money into accounts
- Withdraw money with balance validation
- Display account details
